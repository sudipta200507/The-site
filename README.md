# SecForAI — Security Learning Platform

A structured educational website for learning cybersecurity fundamentals, networking, web security, and penetration-testing concepts.

## Overview

SecForAI is designed as a learning platform for developers and AI/ML engineers who want to build a stronger foundation in cybersecurity.

## Learning Areas

- Computer Networks
- Web Fundamentals
- Web Application Security
- Pentesting fundamentals
- AI concepts
- Machine Learning
- Deep Learning
- Computer-science essentials

## Product Structure

`text
Core Learning
   ├── Networking
   ├── Web Fundamentals
   ├── Security
   ├── Pentesting
   └── AI / ML
`

The website uses a multi-page educational structure with topic pages and shared frontend styling.

## Status

**Educational project / active learning resource.**

## Security Scope

The project is intended for **authorized learning and defensive security education**. Practical security exercises should only be performed against systems where the learner has permission.
